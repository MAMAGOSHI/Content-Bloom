🌸 Content Bloom
Let your ideas bloom.

Content Bloom is an AI-powered content studio designed to help users transform ideas into structured, platform-appropriate content.

The project explores the practical application of Generative AI, prompt engineering, API integration, web development, and modular AI application architecture.

Content Bloom currently supports AI-powered text generation and visual prompt generation, with additional generative AI capabilities designed as future extensions.

Live Application: https://content-bloom.onrender.com/
